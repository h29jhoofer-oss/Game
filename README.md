# The Hollow Depths

A pixel-art dungeon crawler played like a hand of cards. Three years ago the King's castle
sank into the hill in a single night. Go down after it.

## Play

**In your browser:** https://h29jhoofer-oss.github.io/Game/

**Offline:** download [`hollow_depths.html`](hollow_depths.html) and double-click it. It is one
self-contained file — no install, no internet needed. Progress is saved in that browser.

## Controls

| Key | Action |
|---|---|
| Arrows / WASD | move |
| Space | dash (in a fight: strike) |
| 1–9 | play a move card |
| Space, in the glow | parry |
| E | interact · I pack · L codex · T swap off-hand · F lamp oil · H talk to the wisp |
| / | whisper a secret word |

On a phone or tablet, use the on-screen buttons.

Some words only work in the right place, or at the right hour. Read the codex.
