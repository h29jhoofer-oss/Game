# Kingdom Idle

A cozy pixel-art medieval idle kingdom builder (HTML + CSS + vanilla JavaScript).

## Run it
Double-click `index.html` to open it in any modern browser. No install or build step.

## Files
- `index.html` – page layout (resource bar, village, building panel, navigation)
- `style.css` – all styling; colors are variables at the top
- `game.js` – game logic, split into numbered sections
