# Game
For my game

Open `index.html` in a browser to pick a game. No install needed.

## Dungeon Boss (`dungeon.html`)
A reverse side-scroller, inspired by *Hostile Architect*: you are the boss at the end of the level, and heroes run and jump through it to reach you.

- **Build:** spend coins on spikes, saw blades and arrow turrets (click a trap of the same type again to upgrade it, up to level 3), and souls on skeletons and ogres.
- **Fight:** if a hero reaches your lair, A / D move, W jumps and Space swings your cleaver.
- Lava pits kill heroes who miss a jump. Each dead hero gives coins and souls, but the next one is stronger, better geared, and better at spotting traps and dodging.

## Pixel Snake (`snake.html`)
Classic Snake. Arrows / WASD to move, Space to pause, swipe on mobile.
