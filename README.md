# NEON BREAKER

A pixel-art Breakout-style arcade game in plain HTML, CSS and JavaScript (Canvas). No libraries, no build tools, no server.

## Run it

1. Keep `index.html`, `style.css` and `game.js` together in one folder.
2. Double-click `index.html` (or drag it into Chrome, Firefox, Edge or Safari).

## Controls

| Action | Desktop | Mobile |
| --- | --- | --- |
| Move paddle | Mouse, A/D, or Left/Right arrows | Drag finger |
| Launch ball | Space or click | Tap |
| Start / restart | Space, Enter, or the on-screen button | Tap the button |

## Status

**Stage 1 (core prototype) is done:** pixel-perfect scaling, paddle, ball physics, one brick layout, score, 3 lives, title screen, game over and restart.
