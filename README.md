## Algebra 2 Chapter 3 Review Game

Open `index.html` in a browser. Problems are generated randomly for each lesson
from the class review slides:

- 3-1 Solving systems by substitution
- 3-2 Systems of inequalities (pick the point that solves the graph)
- 3-4 Systems with three variables
- 3-5 Operations with matrices

10 problems per round, 3 hearts, streak bonuses, hints, and a worked solution after every answer.
