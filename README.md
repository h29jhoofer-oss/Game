# Lighthouse Keeper

A retro pixel-art night-watch game in a single self-contained HTML file. Open `index.html` in any modern browser; it needs no build step and has no dependencies.

Rotate the lighthouse beam to keep ships in your light so they can find the harbor. Ships left in the dark drift off course and wreck on the reefs. Survive each night from 9 PM to 6 AM.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Rotate beam | Left / Right or A / D | `<` `>` buttons, or drag on the sea |
| Focus beam | Hold Shift or Down | Hold FOCUS |
| Flare | Space | FLARE |
| Foghorn | H | HORN |
| Pause | Escape | Pause icon (top right) |
| Sound on/off | M | Pause menu |

Progress (best score, coins, upgrades and cosmetics) is saved in `localStorage` when the browser allows it.
